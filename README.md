## Cara Menjalankan

```bash
git clone https://github.com/daff40/python-untuk-pemula.git
cd python-untuk-pemula
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python pengenalan_python.py
```

Bukti hasil eksekusi tiap bab ada di folder `screenshots/`.
